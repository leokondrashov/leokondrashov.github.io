This course covers embedded systems programming on STM32 microcontrollers. I mentored students in:

- ARM Cortex-M architecture and programming
- STM32 microcontroller peripherals and interfaces
- Bare-metal C programming
- Embedded systems design principles

Students learned to develop embedded applications from scratch, including interrupt handling, DMA configuration, and communication protocols (UART, SPI, I2C).
