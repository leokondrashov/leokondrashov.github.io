This course focuses on advanced C++ programming concepts and best practices. Mentoring students through:

- Object-oriented programming principles
- Template programming and design patterns
- Memory management and performance optimization
- Modern C++ features (C++11/14/17)

Course was part of Technotrack program at Moscow Institute of Physics and Technology (MIPT). Students gained practical experience in software development and problem-solving skills.
